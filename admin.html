Chưa kết nối Supabase

Điền Project URL và anon key vào supabase-config.js để bắt đầu.

  1. Tạo project tại supabase.com.
  2. Chạy SQL: mở SQL Editor, dán toàn bộ supabase/setup.sql rồi Run.
  3. Tạo tài khoản admin: Authentication → Users → Add user (nhớ bật Auto Confirm).
  4. Lấy key: Project Settings → API → copy Project URL và anon/publishable key.
  5. Dán vào file supabase-config.js: 
    window.SUPABASE_CONFIG = {
    url: "https://abcdefgh.supabase.co",
    anonKey: "eyJhbGciOiJIUzI1NiIs..."
};

Hướng dẫn đầy đủ: HUONG-DAN-SUPABASE.md
